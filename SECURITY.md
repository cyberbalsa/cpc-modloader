# Security reports

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/cyberbalsa/cpc-modloader/security/advisories/new). Include the affected loader version, OS, reproduction steps, and impact. Use synthetic files and redact credentials and personal information.

Security fixes target the latest release. Ordinary crashes and compatibility problems belong in the bug-report form.

Mods execute Lua in the game and must be trusted. The loader is not a sandbox for hostile mods. Path traversal, writes outside the intended profile/mod boundaries, and flaws in update or launch handling are appropriate security reports.
